# Preview assets

`screenshot.png` and its SVG source were generated from a captured FFetch-3D
terminal frame using Arch artwork loaded by the installed Fastfetch. The
preview uses blocks and the Electric Cyan preset. Its information fields are
explicit example values; the username/hostname title is replaced with
FFetch-3D. The SVG preserves captured character positions and foreground
colors, with a dark background and a monospace font.

The root `demo.gif` and the shading images in `docs/` are inherited upstream
assets, retained with the original project's attribution and ISC notice.
The original animation is not presented as a demo of the new neon palette.
